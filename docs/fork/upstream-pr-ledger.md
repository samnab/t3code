# Upstream PR ledger

The allowlist and decision record for upstream pull-request intake. One row is
one upstream PR. States: `candidate`, `evaluating`, `accepted`, `deferred`,
`rejected`, `superseded`, `removed-after-upstream-merge`.

Provenance rule: no upstream PR is merged into integration ancestry. Provider-
specific behavior is extracted onto current architecture seams with the source
commit, author, and license recorded here; fork-owned reworks carry the
original authorship via recorded provenance or `Co-authored-by` trailers.

Intake baseline verified against the GitHub API at 2026-08-29.
